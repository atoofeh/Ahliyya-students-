# iOS app

The iOS app uses the same React screens and API as Android, wrapped with Capacitor 8. Its native layer stores refresh tokens in iOS Keychain, keeps a hashed device binding, opens downloaded documents in the iOS document preview, and hides app content in the app switcher and during detected screen recording or mirroring.

## Build on a Mac

Install Node.js 22 or later and Xcode 26 or later on the Mac, then open the repository in Terminal. Capacitor 8 uses Swift Package Manager here, so CocoaPods is not needed.

```sh
cd client
npm install
npm run build:ios
npx cap open ios
```

In Xcode, select the **App** scheme and a simulator or connected iPhone. For an iPhone, open the App target's **Signing & Capabilities**, select a team, and let Xcode manage signing. Press **Run** to compile and install. For App Store distribution, the bundle ID `com.alahliyya.lms` must be available to the Apple Developer account used to sign it.

`npm run build:ios` packages the production API address from the checked-in `client/.env.ios`, builds the shared web app, and syncs it into `client/ios`. The native project and Swift plugin are already in this repository; the Mac is needed for Xcode builds and signing.

## Features and platform limits

- The app uses the same login, roles, courses, quizzes, lessons, and server as Android.
- Keychain stores remembered refresh tokens. The device ID is hashed on-device and retained in Keychain across reinstalls.
- Downloaded documents open in the iOS document preview. Local notifications are supported.
- Closed-app cloud push is not enabled for iOS yet. The current server expects Firebase Cloud Messaging registration tokens, while Capacitor's iOS push plugin provides an APNs token. The client deliberately does not register that incompatible token. Apple push credentials and Firebase iOS messaging setup are needed before enabling it.
- iOS does not provide apps a supported API to block the screenshot buttons. It reports a screenshot after capture; during quizzes this is sent to the anti-cheat event endpoint. When iOS reports screen recording or mirroring, the app covers the view and pauses video playback. It also covers the view as the app leaves the foreground so the app switcher preview does not show course content. The cover reacts to the OS signal, so a brief capture may occur before it appears. A second device camera can still record the screen.

## Updating native dependencies

After changing Capacitor plugins or dependencies, run `npm run build:ios` on the Mac. Xcode resolves the Swift Package Manager dependencies when the project opens. Keep `ios/App/CapApp-SPM/Package.swift` generated by Capacitor CLI; add JavaScript Capacitor plugins through `package.json` and then sync.
