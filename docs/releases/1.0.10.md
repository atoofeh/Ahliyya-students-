# Feker 1.0.10

Prepared November 23, 2026 (Asia/Amman).

## Changes

- VideoPlayer: Fixed the stuck buffering overlay ("جارٍ تحميل الفيديو..." / `waiting` state) during uninterrupted playback on mobile/WebKit by removing `setWaiting(true)` from download socket stall events (`onStalled`), guarding `onWaiting` when future frames are ready (`readyState >= 3`), adding self-healing timeupdate checks, and clearing waiting on play, seek, and restore.
- Completed enrollment authorization: Students with completed enrollments (`status: 'completed'`) can continue accessing course videos and materials without receiving 403 `NOT_ENROLLED`.
- SPA cache-control headers: Nginx configured with `no-cache, no-store, must-revalidate` on entry routes so desktop and mobile clients always pull fresh application code on load.
