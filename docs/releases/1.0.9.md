# Feker 1.0.9

Prepared November 19, 2026 (Asia/Amman).

## Changes

- Owner and administrator pages use readable cards, wrapping filters and touch-sized actions on phones and tablets. Navigation becomes a drawer below 1280px. Wide desktop tables and sidebar remain available. Account forms, security tabs, sessions, audit, announcements, dashboard and settings adapt to narrow screens in English and Arabic.
- Course search matches literal partial text in titles, descriptions, categories and tags, including Arabic. Searches keep publication and staff-access filters, reset pagination, cancel obsolete requests and show recoverable errors. Teacher course lists also offer search.
- Account and administrator creation forms offer an optional Generate password button. It uses the browser's cryptographic random generator to produce a 16-character password satisfying the server policy; manual entry remains available.
- One video dropdown offers 0.5×, 0.75×, 1×, 1.25×, 1.5×, 1.75× and 2× playback. Selection survives stream renewal and preserves audio pitch where supported.
- The identity watermark starts after 2.5 seconds, stays visible for 18 seconds and changes position every 6 seconds, with randomized 14–22 second gaps. It remains small, translucent and unable to intercept controls. Reduced-motion users receive stationary bursts. This helps identify footage filmed with another phone; it cannot prevent an external camera.

## iOS handoff

The native project and embedded assets are prepared as `1.0.9`, build `13`. On a Mac, run `npm ci`, `npm run build:ios` and `npm run ios:open` from `client`, confirm the available App Store Connect build number, then test/archive/sign with Xcode. Installed Apple apps need an updated app build to receive the shared-player changes. No signed iOS archive or App Store upload was produced on Windows.

## Deployment

Deploy the production website assets with the entry HTML last, retaining old hashed assets for existing browser tabs. The only API file changed in this release is `server/src/modules/courses/courses.service.js`; restart the API after installing it. No database migration or media change is needed. Actual production verification is recorded in `docs/SERVER_CONTEXT.md`.
